# Jess microphone input selection

Jess can use the browser/installed app's default microphone or a specific connected audio-input device, such as the laptop microphone, a USB/Bluetooth headset microphone, or another microphone exposed by the operating system.

Open Jess's floating action menu and use **Microphone input**. The selection is stored in this browser profile and applies the next time Jess connects; if a session is active, changing it reconnects Jess to the selected input. The browser must grant microphone permission before device labels are reliably available. Newly connected devices are refreshed when the OS/browser reports a device change.

This selects one microphone input at a time. It does not mix laptop and headset microphones simultaneously. If the selected device is disconnected or unavailable, choose **System default microphone** or select another listed input. Available devices and background behavior depend on the browser, operating system, installed app bridge, and microphone permissions.
